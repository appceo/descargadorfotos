Publicar gratis en GitHub Pages

Para tener esta aplicación disponible online de forma continua y reutilizable desde cualquier navegador, sigue estos pasos:

  1. Guarda el código: Guarda este código en tu PC con el nombre de archivo index.html.
  2. Crea un repositorio en GitHub: Ingresa a GitHub.com, crea un nuevo repositorio público (ejemplo: extractor-fotos).
  3. Sube el archivo: Dentro del repositorio, haz clic en Add file > Upload files y arrastra el archivo index.html. Haz clic en Commit changes.
  4. Activa GitHub Pages:
    • Ve a la pestaña Settings (Configuración) de tu repositorio.
    • En el menú izquierdo, busca la sección Pages.
    • En Build and deployment > Branch, selecciona la rama main o master y guarda (Save).
  5. ¡Listo!: En unos segundos GitHub te proporcionará un enlace web permanente (ejemplo: https://tu-usuario.github.io/extractor-fotos/) utilizable las veces que quieras.
