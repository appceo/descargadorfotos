Publicar gratis en GitHub Pages

Para alojar esta aplicación en GitHub y usarla múltiples veces:

  1. Guarda este código en tu computadora como index.html.
  2. Crea un repositorio público en tu cuenta de GitHub.
  3. Sube el archivo index.html al repositorio.
  4. En Settings > Pages, selecciona la rama main y guarda.
  5. Abre el enlace generado por GitHub para usar la herramienta ilimitadamente.
